## 2. 카드뉴스(캐러셀)에서 저장·공유를 늘리는 법

- **1~3장이 각각 첫 장 역할을 해야 한다.** 피드에서 2·3번째 장부터 보이는 경우가 있으므로, 2·3장만 봐도 멈추게 만든다. [원포인트](https://1point.kr/blog/insights/why-insta-carousel-2026/)
- **10장 이내.** 우리는 7장이라 적당하다.
- **저장은 '나중에 꺼내 볼 정보'에서 나온다.** 가격·날짜·장소 같은 facts 칸이 이 역할을 한다. 예쁜 감상용 이미지는 좋아요만 받는다. [linkfarm](https://linkfarm.ai/blog/instagram-carousel-content-guide-2026)
- **DM 공유는 받을 사람을 콕 집어야 늘어난다.** 예: "편의점 털러 갈 친구한테 보내기". '@@ 태그'보다 구체적으로 쓴다. [원포인트](https://1point.kr/blog/insights/why-insta-carousel-2026/)
- **직접 만든 자료가 유리하다.** 남의 사진을 캡처해 모으는 방식은 추천에서 불리할 수 있다. 우리는 공식 보도자료 사진에 우리 디자인을 입히므로 괜찮다. 다른 계정 게시물을 캡처해 쓰는 것만 금지. [nikumashop](https://nikumashop.com/tips/instagram-recent-update-checklist)
- **릴스로 새 사람에게 닿고, 카드뉴스로 저장시킨다.** 릴스가 비팔로워 도달에 강하다는 글이 많다. [highoutputclub](https://blog.highoutputclub.com/2026-instagram-algorithm-update/)

## 3. 다섯가지에 적용할 것 (우선순위)

1. **[적용함] 마무리 장 공유 문구를 구체적으로:** STYLE_GUIDE의 outro.lines에 "OO한 친구한테 보내기" 형태를 넣는다.
2. **[적용함] 2번 슬라이드(1번 품목)도 표지처럼:** 1번 품목은 제목만 봐도 멈출 만한 것으로 둔다. 표지 점수 2위 품목을 1번에 배치.
3. **[해볼 것] 게시 시간 실험:** 지금은 11:30 이후 자동 게시. 한 소비 패턴 분석은 평일 밤 10시 무렵을 피크로 본다. [큐레터](https://www.i-boss.co.kr/ab-qletter-971123) 2주씩 점심(12시)과 밤(21시)을 번갈아 보고 인사이트의 도달·저장을 비교한다. API 게시로 바꾼 뒤 하는 게 깔끔하다.
4. **[해볼 것] 댓글 키워드 → DM 링크:** @20s_mag와 낼나샵에서 댓글이 10배 이상 나온 방식. 공식 API(instagram_business_manage_messages 권한)가 생긴 뒤 자동화 가능하다. 그전에는 하지 않는다 (사람이 답해야 함).
5. **[해볼 것] 릴스 1주 1개:** 7장 슬라이드를 3~5초씩 이어 붙인 슬라이드쇼 릴스로 새 사람에게 닿게 한다. render.py 결과물로 만들 수 있다.
6. **[나중에] 매일 같은 시간 루틴:** 최고심처럼 "매일 오전 몇 시"를 고정하면 팔로워 습관이 된다. 게시 시간 실험이 끝나면 고정.

### 업계 자료 (검증 안 된 수치는 방향만 참고)
- Buffer 210만 게시물 분석: 주 3~5회 게시 계정의 팔로워 증가가 주 1~2회의 약 2배. → 초반 빈도 늘림. [SocialRails](https://socialrails.com/blog/instagram-posting-frequency-guide)
- 인스타 검색은 캡션 글을 읽음. 첫 두 줄에 검색어. → 캡션 첫 줄에 '편의점 신상', '이번주 팝업' 같은 말. [snsmeme](https://snsmeme.com/blog/instagram-seo-essentials-2026-guide)
- 표지 1장: 답을 숨기고 궁금하게, 피드에서 작게 봐도 글자가 읽혀야 함. 2·3장은 단독으로 노출될 수 있음. [원포인트](https://1point.kr/blog/insights/high-save-cardnews-formula/), [Metricool](https://metricool.com/instagram-carousels/)
- 사진·캐러셀에 음악을 넣으면 릴스 탭에도 노출될 수 있음. [dataslayer](https://www.dataslayer.ai/blog/instagram-algorithm-2025-complete-guide-for-marketers) → 웹 게시 화면에선 음악을 못 넣음. API 게시로 바꾼 뒤에도 미지원이라 보류.

### 그래서 바꾼 것
1. 표지: 사진 1장(크고 세로에 가까우면 꽉 채움, 작거나 가로형이면 통째로 넣고 뒤를 흐리게) + 묶음 전체를 말하는 제목 + 강조어 1개 색 박스 + 시리즈 이름 말풍선 + '넘겨보기'. 다섯 장 콜라주는 시험해 보고 버림(아무것도 안 보임).

3. 마무리 장: 공유 한 줄 강조.
4. 캡션: 첫 줄 검색어, 해시태그 5개, '@@ 태그' 폐지.
5. 빈도: 하루 2편 (아침 07:30~, 저녁 19:00~), 2026-11-22에 인사이트 보고 재조정.
